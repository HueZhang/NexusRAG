# 数据目录说明

本目录存放 NexusRAG 的语料与评测数据。**原始语料体积大，不进 Git**；只保留结构说明与评测集。

```
data/
├── raw/          # 原始抓取文件（PDF/HTML/JSON），体积大 → 不进 git
├── processed/    # 清洗、切分后的中间产物 → 不进 git
├── eval/         # 评测问答集（小体积、高价值）→ 进 git
└── README.md     # 本文件
```

## 数据来源与合规原则

- 仅使用**公开、无需登录、面向大众**的药品说明书 / 医疗器械法规类语料。
- **不涉及任何患者病历、处方等个人隐私数据**。
- **不绕过登录 / 付费墙**，遵守目标站点 robots.txt，礼貌限速抓取。
- 首个场景：医疗说明书合规问答（如大医网药品说明书、NMPA 药品基础数据）。

## 如何获取（复现）

1. 参见 `raw/medical/MANIFEST.md`（每次抓取记录来源 URL 列表、时间戳、脚本版本）。
2. 原始文件不随仓库分发；按 MANIFEST 重新抓取即可复现。
3. 清洗后产物写入 `processed/`，向量库落在 `processed/` 下（均不进 git）。

## 评测集（eval/）

- `medical_qa_dev.jsonl`：人工构建的药品问答对（问题 / 参考答案 / 出处），
  用于 RAGAS 式评测（Context Relevance / Faithfulness / Answer Relevance）。
- 评测集**进 git**，是项目可复现性与"会做评测"的证明。
